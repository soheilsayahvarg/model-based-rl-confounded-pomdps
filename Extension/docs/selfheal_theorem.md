# Self-Healing, Proved: An Exact Span Formula and the Side Condition It Exposes

**Written and committed before the verification was run.** The measurement
sections are empty on purpose.

---

## 1. What we currently have, and why it is not enough

`cor:selfheal` says an inadequate negative control is partially self-healing:
per-action completeness is restored at every stage after the first. The evidence
is a measurement, 24/24 population cells at every confounding level below 1, plus
a stage-by-stage check out to `t = 5`.

A measurement over one environment family is the weakest form this result can
take. It also gives no account of the one place it fails. At confounding exactly
`1` the span collapses back to the `t = 1` value, and we currently call that
point "contrived" without saying what breaks.

The smoke test for `run_stage_selective.py` supplied the missing piece by
accident. It printed the numerical null dimension of the empirical stage-2 design
per block:

    null dim   bR_t1 = 96,  bR_t2 = 0,  bR_t3 = 0,  bD_t1 = 288,  bD_t2 = 0

Zero, not small. The `t >= 2` design is not merely rich enough to contain the
truth; it has no null space at all. That is a statement about the design matrix,
and a statement about a matrix should be provable.

## 2. The formula

Fix an action `a`. The `t = 2` per-action design profiles are, over the
conditioning cells `(o_1, a_1, o_0)`,

    profile(o_1, a_1, o_0)  proportional to  E^T ( E[:, o_1] * u_{a_1, o_0} )

where `*` is elementwise and

    w_{a_1, o_0}[s_1] = p_1[s_1] * K_0[s_1, o_0] * pi_b[s_1, a_1]
    u_{a_1, o_0}[s_2] = (w_{a_1, o_0}^T P[a_1])[s_2] * pi_b[s_2, a]

Normalizing each column divides it by a positive scalar, which does not move the
span.

**Claim.** Let `Supp_a` be the union over `(a_1, o_0)` of the supports of
`u_{a_1, o_0}`. If `E` has rank `|S|`, then the `t = 2` per-action design span is

    span = E^T { z : supp(z) subset of Supp_a }
    dim  = rank( E[Supp_a, :] )

**Proof.** Fix `(a_1, o_0)` and write `u = u_{a_1, o_0}`. Because `E` has rank
`|S|`, the columns `{E[:, o_1]}` span `R^{|S|}`. Elementwise multiplication by a
fixed `u` maps `R^{|S|}` onto exactly `{z : supp(z) subset of supp(u)}`. So the
profiles generated by that `(a_1, o_0)`, varying `o_1`, span
`E^T {z : supp(z) subset of supp(u)}`. Summing the subspaces over all
`(a_1, o_0)` replaces `supp(u)` by the union, and applying `E^T` to a spanning
set of `R^{Supp_a}` gives a space of dimension `rank(E[Supp_a, :])`. QED

At `t = 1` the same argument gives only `|O_0|` profiles with no free `o_1`
index, so the span is at most `min(|O_0|, |S|)`. **The whole of self-healing is
the appearance of a free observation index in the conditioning set.** That is
why history substitutes for the instrument, and it is one line rather than a
table.

## 3. The side condition, which is the point

Self-healing is not automatic. It holds iff `Supp_a = S`, and

    Supp_a = { s : pi_b[s, a] > 0 }  intersect  ( union over (a_1, o_0) of
                                                  supp( w_{a_1,o_0}^T P[a_1] ) )

Two ways to break it, and only the first is in the literature:

1. **Saturated confounding.** At confounding `1`, `pi_b[s, a] > 0` only for
   `s = a mod |A|`, so `Supp_a` has `|S| / |A|` elements. This is the knife-edge
   we measured and did not explain.
2. **Reachability.** If `P` is sparse enough that some state is unreachable in
   one step from the initial support, `Supp_a` misses it at **every** confounding
   level, including zero. Our environment family draws every transition row from
   a Dirichlet, so `P` is dense and this case has never been generated. It is
   not exotic: a system with irreversible states, absorbing failure modes, or a
   staged process where early states cannot recur has exactly this structure.

If (2) is real, `cor:selfheal` as currently stated is false without a
reachability hypothesis, and every result downstream of it inherits that
hypothesis, including the remedy in `stage_selective_pessimism.md`.

## 4. Predictions

- **P-S1 (control).** In the current dense family, at every confounding below
  `1`, `Supp_a = S` and the measured span equals `|S|`. This reproduces what we
  already know and is evidence of nothing; it is here so a formula that got the
  easy cells wrong would be caught.
- **P-S2.** At confounding exactly `1`, `Supp_a = {s : s mod |A| = a}` and the
  measured span equals `rank(E[Supp_a, :])`, which is `2` for `(4,6,2)` and
  `(4,8,3)` and `1` for `(2,6,4)`. The knife-edge acquires a formula.
- **P-S3 (the real test).** With a transition matrix engineered so one state is
  unreachable in one step from the initial support, the measured `t = 2` span is
  strictly below `|S|` **at every confounding level including `0`**, and
  `beta_2 > 0` there. Self-healing fails with no confounding at all.
- **P-S4 (the theorem).** `rank(E[Supp_a, :])` equals the measured SVD rank in
  **every** cell of the sweep, dense and sparse, all stages, all confounding
  levels. Not a bound. An equality, in every cell.
- **P-S5.** `Supp_a` is monotone nondecreasing in `t`, so a design that is
  complete at some stage is complete at every later stage. Self-healing, once
  it happens, does not un-happen.

P-S4 is the one that can kill this. A single cell where the formula and the SVD
disagree refutes the proof, and we report the count either way.

## 5. What P-S3 would cost us

If sparse transitions break self-healing, three statements need a hypothesis
they do not currently carry:

- `cor:selfheal` needs "under one-step reachability of the full state space".
- The horizon-dilution argument assumes exactly one block leaks, which is what
  bounds the floor as constant in `T`. Under a reachability failure the leak
  would recur at every stage and the floor would compound.
- The stage-selective remedy would apply only to reachable-support problems, and
  the pre-fit check would gain a third item beyond the two switches.

That is a worse paper in one sense and a better one in another: a corollary with
a stated side condition that we found ourselves is more useful than a corollary
that is silently false on a class of problems the reviewer will think of.
